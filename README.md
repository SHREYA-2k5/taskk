 # TaskFlow – Task & Team Management Platform

TaskFlow is a full-stack task and team management application designed to help individuals and teams organize tasks, manage priorities, track progress, and collaborate efficiently.

### Features
- Secure user registration and login with JWT authentication
- Create, view, update, delete, and assign tasks
- Track task status, priority, and due dates
- Dashboard with task statistics and progress visualization
- Search, filtering, sorting, and pagination
- Team directory and task assignment
- Responsive interface with dark mode and toast notifications

### Tech Stack
- **Frontend:** React, Vite, React Router, Axios, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas with Mongoose
- **Authentication:** JWT and bcryptjs
- **Testing:** Automated tests for backend validation and frontend utilities
